UI STRINGS TASK
Translate i18n/ui.en.json (the page's buttons, labels, notices and sentence templates) into your language and
write i18n/out/<lang>/ui.json with EXACTLY the same keys. Rules from i18n/BRIEF.txt apply (no em dashes, numbers
kept, neutral tone), plus:
- Read i18n/ui.notes.json: per-key notes on where a string appears, what each {placeholder} holds, and length limits.
- Keep every {placeholder} exactly (same names, each used once or as in the English); you may move them anywhere
  in the sentence. Never translate the text inside braces.
- Keys ending _one / _other are plural forms chosen by Intl.PluralRules. Translate both. Russian: ALSO add
  base_few and base_many keys (same base) with the correct Russian forms. Languages without plurals (zh, ko, fa,
  pa as needed): give both keys the same natural text.
- Keys with "kid" or level-1/2 notes are for the simplest reading levels: very short, everyday words.
- Buttons and chips must stay short. Use the glossary (i18n/glossary.<lang>.json) for party names, riding,
  advance voting, reading levels, etc., so the UI matches the quiz text.
- The language-name strings (if any) for the selector stay in their own native script.
- "BC Vote Helper" is the product name: keep it in Latin, you may add a short native description after it
  where it is a heading.
Validate with: python -I i18n_check.py <lang> ui   and fix every ERROR.
